# Пробуждение

Приложение для домашней реабилитации пожилых пациентов: видео-упражнения и когнитивная стимуляция (поиск отличий, четвёртый лишний, пространственные задания, слова из букв, музыка и пение).

Открывается в браузере и ставится на телефон как приложение: https://freaking-bread.github.io/Probuzhdenie/

Содержимое (упражнения, музыка) задаётся в `js/content.js`.
