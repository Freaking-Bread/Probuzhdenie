# Пробуждение

Приложение для домашней реабилитации пожилых пациентов: видео-упражнения и когнитивная стимуляция.

Открывается в браузере и ставится на телефон как приложение: https://freaking-bread.github.io/Probuzhdenie/

## Что внутри

- **Упражнения** — видеоролики; отмечается, что пациент открыл, сколько смотрел и выполнил; можно отправить своё видео.
- **Левое полушарие** — Найди отличия, Четвёртый лишний, Пространство, Слова из букв.
- **Внимание и память** — Цвет в узоре, Запомни порядок, Двойное внимание.
- **Правое полушарие** — музыка с пропеванием и записью голоса.
- **Кабинет координатора** — действия и результаты пациентов по дням, включая число нажатий мимо в «Найди отличия».

Все задания на время; большинство генерируется случайно, в «Найди отличия» 31 картина, в «Словах из букв» 34 набора.

## Установка на телефон

- **iPhone:** Safari → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome → три точки → «Установить приложение».

## Устройство

Обычные HTML, CSS и JavaScript без сборки. Содержимое (видео, музыка, дневные нормы) задаётся в `js/content.js`. Данные сначала сохраняются на устройстве, затем отправляются на сервер, поэтому приложение работает и без интернета.

Запуск на компьютере:

```
python -m http.server 8000
```

и открыть http://localhost:8000

## Источники

- Картины в «Найди отличия» — репродукции в общественном достоянии (Викисклад).
- Слова — открытый словарь Russian-Nouns (Harrix, MIT).
